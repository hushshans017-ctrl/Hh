## Features

### Currency System
- Start with 5000 in-game currency
- Earn currency by:
  - Defeating enemies
  - Completing daily missions
  - Achieving milestones
  - Battle pass rewards

### Rarity Tiers
- **Common** 🟢 - Free, starter skins
- **Rare** 🔵 - 1200 currency
- **Epic** 🟣 - 2000 currency
- **Legendary** ⭐ - 3500+ currency

### Customization
- Equip any unlocked skin
- Each skin has unique colors
- Visual effects based on rarity
- Skin-specific animation effects (future)

### Shop Features
- Browse all available skins
- Preview skins before purchase
- Visual rarity indicators (color-coded)
- Currency balance display
- Lock indicators for locked skins

---

## How to Use

### In-Game
1. Press **S** to open skin shop
2. Browse available skins with **Arrow Keys**
3. Press **Enter** to select/buy
4. Equip skin to start next game

### Mobile
1. Tap **Skin Shop** button
2. Swipe through available skins
3. Tap to preview
4. Tap **Buy** or **Equip**
